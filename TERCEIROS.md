| [ONNX Runtime](https://onnxruntime.ai) + DirectML — Microsoft | Executa a IA na placa de vídeo | MIT |
| [OpenCV](https://opencv.org) | Captura e processamento de imagem (vídeos de fundo pelo decodificador do Windows) | Apache-2.0 |
| [NumPy](https://numpy.org) | Cálculos com imagens | BSD-3-Clause |
| [CustomTkinter](https://github.com/TomSchimansky/CustomTkinter) — Tom Schimansky | Interface moderna | MIT |
| [Pillow](https://python-pillow.org) | Imagens e textos da interface | MIT-CMU |
| [pygrabber](https://github.com/andreaschiavinato/python_grabber) / [comtypes](https://github.com/enthought/comtypes) | Lista de webcams (DirectShow) | MIT |
